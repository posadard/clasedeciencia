<h3>How do I get started</h3>
<p>If ai_chat does not appear to get the benefits of AI Chat Assistant (extension name 'AI Chat Assistant') you will need to replace the default search block in your page layouts.</p>
<ul>
<ol>
1.      Install the extension ai_chat.</ol><ol>
2.      Go to Admin>Extensions>All Extensions>ai_chat - General section and set the Status to ON.</ol><ol>
3.      Configure the search options as required. Remember to save the options.</ol><ol>
4.      Check that ai_chat is working properly.</ol><ol>
5.      Go to Admin>Design><a href="#admin#rt=design/layout" target="_blank">Layouts</a> and delete the default Header section search block in each layout and replace with ai_chat block.</ol><ol>
6.      The set-up of ai_chat should now be complete.</ol>
</ul>

<h3>Search id</h3>
<p>If ai_chat does not appear to autocomplete correctly ensure the search input ID (example < input type="text" id="filter_keyword" >).</p>
